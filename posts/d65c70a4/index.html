DeepSeek Harness配置指南

一、Harness 是什么

大模型负责推理，Harness 负责把模型放进工作环境：给工具、文件权限、上下文、任务循环和插件。

DeepSeek Harness 的核心理念是 “Everything is a Plugin”（一切皆插件），模型、工具、界面都能拆开换掉。驱动插件体系的内核叫 Cordis。

二、安装与启动

准备

  • Node.js ≥ 22（官网下 LTS 版）
  • DeepSeek API Key：在官网 https://platform.deepseek.com/api_keys 创建

安装

建议全局安装，以后直接 dsh web 启动：

首次配置

  1. 浏览器打开后，填入 DeepSeek API Key 并保存
  2. 选择一个空文件夹作为工作区
  3. 发条消息测试

三、模式选择

模式 能力 适用场景
标准模式 全套工具，正常写代码改仓库 日常任务
PTC 模式 把多步操作合成一次 TypeScript 调用 批量操作、省 token
极简模式 只留两样：持久 bash + str_replace_editor 上下文最小、改文件做小改动、模型评测
创造模式 标准能力 + 运行时自省、试插件、写 Agent preset 定制自己的 Agent

推荐：轻量用就选极简模式；日常开发用标准模式；需要批量操作再上 PTC。

四、插件系统

安装命令

装完 Ctrl + C 停止服务，重新启动并刷新页面才生效。

插件推荐

核心体验

插件 简介 安装命令
dsh-web-ui-all 一站式全家桶：任务看板+Git图谱+Token统计+皮肤中心+侧边栏工作台+手机远程+电子宠物 dsh plugin --profile web add @linxin666/dsh-web-ui-all

交互方式

插件 简介
deepseek-harness-desktop Electron 桌面 App，无需 Node.js 双击即用
dsh-at-file 输入 @ 弹出文件列表，自动附加内容

能力扩展

插件 简介
ModLens 给纯文本模型装眼睛，贴图能看
dsh-agent-teams 多智能体团队协作，自然语言驱动
dsh-plan-execute 规划用推理模型、执行用经济模型，降本增效
dsh-context-doctor 量化上下文 token 成本，检测重复冲突
dsh-reverse-skill 85 个安全研究技能包，逆向/渗透
