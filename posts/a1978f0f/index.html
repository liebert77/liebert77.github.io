Abnormal log

一名hacker对小蓝鲨正在值守的服务器发起大量攻击，索性被工作人员及时拦截下来，得到一份日志信息，这份日志隐藏什么秘密.(请将得到的flag用ISCTF{}包裹)

攻击者将一个恶意文件切分成了 116 个片段。我们需要提取每个片段中 [INFO] File data segment: 后面的十六进制字符串 ,将这些分段的 16 进制字符串拼接，异或 0x05 就能得到一个 7z 格式的压缩包，解压即可得到 flag

怎么这也能掉链子

vmdk 镜像挂载后，由于 FAT 文件系统表损坏导致簇链不连续，无法正常读取其中的图片文件，拉入 010 可以直接搜索到完整的图片文件，将该图片手动提取出来

有了密文和密钥，维吉尼亚解密即可得到 flag

爱玩游戏的小蓝鲨

美丽的风景照

做题做累了吧，来看看风景吧！

按照出题人所说，将七张图片按照彩虹的颜色排的顺序，即红橙黄绿青蓝紫的顺序，同时古代是从右往左读的，现代是从左往右读的，红橙和青图中是古代物品或建筑，因此这三个字符串需要倒序
最后拼成的是 2WqjC2gD7HLo86yRWhKEaC3ZXw8T98Mz，base58 解码即可得到 flag

阿利维亚的传说

你知道阿利维亚的传说吗

将这三段竖着拼接起来，即可得到完整的 flag
