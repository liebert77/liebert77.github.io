LAMPSecurity: CTF5

将靶机设置为 NAT 模式，启动，我这里配置如下：

漏洞利用

首先使用 fscan 扫一下靶机，发现 22、80 和 3306 等端口开放

先看下 80 端口的 web 服务，是一个博客网站，用的框架是 NanoCMS

搜索发现该 CMS 存在信息泄露，在 /data/pagesdata.txt 会泄露用户名和密码 hash

CMD5查一下得到密码明文 shannon，有了账号密码，直接登陆进入管理员后台

在后台界面的 Pages & Options 中，编辑一下 Contact 页面的内容，添加一个反弹 shell 的木马，保存界面，然后访问 http://192.168.52.135/~andy/index.php?page=contact 即可成功反弹到 shell

权限提升

成功拿到 shell，尝试提权，发现 /home 目录下有很多用户，使用查找命令查找 pass 字样，发现 Root password 字样的文件，访问该文件发现 root 密码 50$cent

得到密码后直接切换 root 用户输入密码，成功提权至 root

LAMPSecurity: CTF6

将靶机设置为 NAT 模式，启动，我这里配置如下：

漏洞利用

首先使用 fscan 扫一下靶机，发现 22、80 和 3306 等端口开放

先看下 80 端口的 web 服务，没发现什么能利用的东西，开始目录扫描

扫到 sql 目录，访问发现一个 db.sql 文件，打开找到管理员账号密码 admin/adminpass

成功登陆后台，点击 Edit this event，上传图像的地方上传一个反弹 shell 木马文件 shell.php，上传之后点击 Home 就能触发访问木马，靶机开启监听，成功反弹 shell

权限提升

UDEV 提权，使用 8478.sh 脚本提权

先把脚本复制到当前目录，再在攻击机上起一个 http 服务，方便靶机下载提权脚本，靶机下载后给脚本添加一个可执行权限

然后获取一下 netlink 套接字的状态信息，选择 Groups 为 ffffffff 的进程，记住 PID，这里是 568，再用 sed 命令将文件中的 Windows 换行符（\r\n）转换为 Unix 换行符，最后执行脚本即可成功提权

将靶机设置为 NAT 模式，启动，我这里配置如下：

漏洞利用

首先使用 fscan 扫一下靶机，发现 22、80、8080 和 10000 等端口开放

有三个 http 服务端口，依次查看：

80 端口没发现什么东西，尝试目录扫描，扫到一个 /assets/ 目录，用来存放图片文件的

8080 端口开放的是一个登陆页面，尝试万能密码成功登陆

登陆后台后，在 Manage Offerings->Reading Room->Add new 这里可以上传图片，直接上传一个反弹 shell 的木马文件，成功上传了，在 80 端口的 /assets/ 目录里发现上传的木马

靶机开启监听，然后访问木马文件，成功拿到 shell

权限提升

尝试进行提权，主流方法都不行，查看 web 源码里的数据库配置文件，发现 root 用户的密码配置为空，于是直接 mysql 进入数据库中找线索

在 website 数据库的 users 表中找到一堆账号和密码 hash

一看就知道第一个用户不简单，is_admin 的值也是 1，先用 CMD5 查到密码明文是 my2cents，再强制 ssh 连接，输入密码即可成功登陆 brian 用户

sudo -l 命令检查下当前用户权限，发现权限较高，直接以 root 权限启动一个新的 bash shell，成功提权
