哥斯拉

哥斯拉流量特征

HTTP 头部特征：

  • User-Agent：默认使用Java客户端的UA（如 Java/1.8.0_121），可能暴露JDK版本信息，但支持自定义UA，该特征较易被修改，属于弱特征。
  • Accept字段：默认值为 text/html, image/gif, image/jpeg, *; q=.2, /; q=.2，与JDK默认行为相关，也支持自定义修改，属于弱特征。
  • Cookie特征：请求包中的Cookie值末尾通常包含分号（如 PHPSESSID=xxx;），属于强检测标识。

响应包特征：

  • 响应包的结构特征：md5前十六位+base64+md5后十六位

冰蝎 3&4

冰蝎3.0流量分析

冰蝎3.0流量特征

HTTP 头部特征：

  • User-Agent：冰蝎3.0内置了 16 种老旧浏览器UA（如 Mozilla/5.0 (Windows NT 6.1; WOW64) AppleWebKit/535.1…），这些UA在现实中很少使用，可作为检测依据。同一IP短时间内切换不同UA时高度可疑。
  • Content-Type：所有POST请求的 Content-Type 固定为 application/octet-stream，这是冰蝎3.0的强特征（服务端代码强制要求），用于传输二进制加密数据。
  • Accept 字段：默认值为 text/html, image/gif, image/jpeg, *; q=.2, */*; q=.2，该格式与常规浏览器不同，属于弱特征。
  • Connection：默认使用长连接（Connection: Keep-Alive），减少握手次数，与高频操作时的低流量形成对比。

首次请求体特征：

  • 首次密钥请求的 Content-Length 固定为 16字节（连接密码的 MD5 前16位）。

默认密钥：

若使用默认配置，密钥为连接密码的MD5前16位（如默认密码 rebeyond 对应 e45e329feb5d925b），但支持用户自定义密钥。

冰蝎4.0流量分析

冰蝎4.0流量特征

HTTP 头部特征：

  • User-Agent 随机化：冰蝎4.0内置了 10种老旧浏览器的UA头（如 Mozilla/5.0 (Windows NT 6.1; WOW64)），每次连接时随机选择。同一IP短时间内切换不同UA时高度可疑。
  • Content-Type：POST请求的 Content-Type 通常为 Application/x-www-form-urlencoded。
  • Accept 字段：默认值为 Accept: application/json, text/javascript, */*; q=0.01，表示客户端优先接受JSON和JavaScript类型数据，与常规浏览器行为存在差异。
  • Connection 字段：默认使用长连接（Connection: Keep-Alive），减少握手次数。

默认密钥：

和冰蝎 3.0 一样，默认配置中密钥为连接密码的MD5前16位（如默认密码 rebeyond 对应 e45e329feb5d925b），但支持用户自定义密钥。
